TOUR VIEWER

1. Open js/config.js
2. Replace the API URL with your Google Apps Script Web App URL.
3. Upload the whole folder to GitHub.
4. Enable GitHub Pages from main / root.

Image behavior:
- Gallery appears after opening a tour.
- Click a photo for full-screen viewer.
- Left / Right arrows and keyboard ArrowLeft / ArrowRight switch photos.
- ESC closes the viewer.
- Mobile horizontal swipe switches photos.
- No custom zoom is implemented.
- Native browser/device pinch zoom, long-press/save, and context menu are intentionally left enabled.
