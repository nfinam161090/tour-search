TOUR VIEWER - GitHub Pages

1. Open js/config.js
2. Replace PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE with the Google Apps Script Web App URL.
3. Upload the entire folder contents to a GitHub repository root.
4. GitHub -> Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
5. Open the published Pages URL.

The first page loads only the tour list from Apps Script.
Images and tour details are requested only after clicking a tour.

Viewer:
- Left / Right arrows
- ESC closes
- Mouse wheel zoom
- Double-click zoom
- Mobile swipe left / right
- Pinch zoom on touch devices
- Next image preloaded
- Tour details cached after first open
